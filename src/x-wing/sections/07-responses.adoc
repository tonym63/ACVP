[[X-WING_responses]]
== X-WING Test Vector Responses

The X-WING response object defines th JSON format returned by the implementation under test (IUT) after processing ACVP test vectors. Response objects contain the values generated by the iut and are returned to the ACVP server for validation.

=== Response JSON Structure
The top-level response object contains the following properties.
|===
| Property | Description

| acvVersion
| Version of the ACVP protocol.

| vsId 
| Vector set identifier assigned by the ACVP server.

| testGroups
| Array of one or more response test groups.
|===

=== Response Test Groups
Each response test group contains the results for one or more test cases.
|===
| Property | Description

| tgId
| Test group identifier.

| tests
| Array of response test cases.
|===

=== Response Test Cases
Each response test case contains the results generated by the IUT for the requested X-WING function.
|===
| Property | Description

| tcId 
| Test case identifier.

| ...
| Function-specific response values as defined in the corresponding KeyGeneration and EncapDecap response specifications.
|===

=== Example Response
[source, json]
----
{
    "acvVersion": "1.0",
    "vsId": 42,
    "testGroups": [
        {
            "tgId": 1,
            "tests": [
              {
                 "tcId": 1
               }   
            ]
         }
       ]
    }

----

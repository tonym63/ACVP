== Test Types and Test Coverage

[#ttypes]
=== Test Types

The ACVP server performs a set of tests on the specified X-WING algorithm in order to assess the correctness and robustness of the implementation. A typical ACVP validation session would require multiple tests to be performed for every supported permutation of X-WING capabilities. This section describes the design of the tests used to validate implementations of the X-WING algorithms.

=== X-WING / keyGen / "AFT"

- Algorithm Functional Test (AFT)

The ACVP server provides the IUT with a 32-byte decapsulation key sk.  The IUT shall use the provided sk to perform the deterministic X_WING key-generation procedure, GenerateKeyPairDerand(sk), and return the resulting 1216-byte encapsulation key pk.  This test vereifies that the IUT correctly implements the X-WING key derivation and key-generation procedure defined in section 5.2 and 5.2.1 on th X-WING specification.

=== X-WING / encapDecap / "AFT"

- Algorithm Functional Test (AFT)

The IUT shall perform the X-WING encapsulation or decapsulation operation using the values provided by the ACVP server and return the resulting ciphertext and shared secret, as applicable, for validation.  The test verifies that the IUT correctly implements the X-WING EncapsulateDerand() and Decapsulate() procedures defined in Section 5.4.1 and 5.5 of the X-WING specification.

=== X-WING / encapDecap / "VAL"

- Validation Test (VAL).

For X-WING encapDecap Validation testing the ACVP server provides the IUT with an X-WING decapsulation key (sk) and cipherText (ct).  Validation testing includes both unmodified and modified-ciphertext test cases.  The IUT SHALL perform the X-WING Encapsulate(ct, sk) procedure for each test case and return the resulting 32-byte shared secret (ss) to the ACVP server for validation.  The test verifies that the IUT correctly processes X-WING ciphertext in accordance with the decapsulation procedure defined in Section 5.5 of the X-WING specification.

These tests verify the implementation of the X-WING decapsulation procedure defined in Section 5.5 of <<XWING>>


=== Test Coverage
The tests described in this document are intended to ensure that an implementation conforms to the X-WING specification.  X-wing relies on ML-KEM-768 as specified in the fiPS <<FIPS203>> as a cryptographic dependency.

- Requirements covered

The test ensure the conformity and correctness of the X-wiNG key-generation, encapsulation and decapsulation operations supported by the implementation.

- Requirements Not Covered

Requirements that cannot be verified through the ACVP testing interface are outside the scope of ACVP testing.  These include implementation specific security requirements such as the secure generation of random values protection of secret and intermediate values and implementation characteristics intended to mitigate attacks.
